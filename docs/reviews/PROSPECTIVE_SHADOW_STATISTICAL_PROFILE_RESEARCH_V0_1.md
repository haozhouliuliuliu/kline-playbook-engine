# 前瞻 Shadow 统计检验档案研究 V0.1

## 结论

`PROSPECTIVE_SHADOW_STATISTICAL_PROFILE` 不能在本阶段锁定。此结论不使用任何
候选历史收益、逐笔结果、PnL 或通过率；它是对研究方法充分性的预先审查，不是策略结果。

## 最小阻塞点

项目尚未验证并采纳一套同时明确下列四项且适用于稀疏、序列相关、偏态交易事件的
前瞻方案：

1. 事件权重的收益估计量与零假设；
2. 串行相关与跨品种依赖的处理方式；
3. 批次/聚类边界及连续监控的 e-process 或等价顺序阈值；
4. 多重比较下强 FWER（家族错误率）控制，且不改变已冻结的事件权重估计量。

目前 Route A+D 只说明历史正向通过不再是本阶段的前置条件；它没有自动给出一份可用于
前瞻 Shadow 的完整统计档案。若现在填写任何阈值、最小样本量或通过规则，均属于无证据的
项目侧发明，违反预先锁定原则。

## 决策

- 档案状态：`NOT_LOCKED_METHOD_INSUFFICIENT`。
- 研究波次状态：`DRAFT_ONLY`；不得构造锁定的 `ResearchWaveManifest`。
- 后果：禁止解锁候选结果评估与任何“通过/失败”的交易结果结论。
- 不受影响：Holy Grail 主策略、StrategyIdentity、Qualified Eligibility View 和 E07 映射
  可继续作为无结果的工程与登记输入。

## 最短补齐路径

提供并经项目 authority 采纳一份只定义方法、不读取候选结果的统计档案：固定估计量、
依赖/聚类模型、连续监控规则、强 FWER 规则、停止规则和审计字段。采纳后才可创建并锁定
前瞻 Shadow 研究波次。
