Define the current project treatment of the frozen historical 12/6/6 evidence path after the Common Statistical Profile inference-resolution package.

This policy supplements but does not amend Research Protocol v1.0.


## 4. Outcome access

This policy unlocks no outcome-bearing research.


## 5. Authorized work while positive acceptance is parked

The project continues the Human Playbook First pipeline before outcome testing:

```text
traceable source
-> SOURCE_ONLY claim extraction
-> SOURCE CLAIM / PROJECT INTERPRETATION separation
-> observability assessment
-> ambiguity / failure / negative evidence preservation
-> exactly-one PRIMARY preparation where source-justified
-> deterministic non-outcome operationalization
-> governed evidence / identity / lineage engineering
```

The project must not turn source extraction into hidden data-first search.

## 6. Future positive-acceptance path

A future positive-acceptance path requires a separately authorized research-design package.

Possible classes may include genuinely prospective evidence, longer evidence windows, or a rigorously justified restricted inference domain, but none is approved by this policy.

Any change to frozen chronology or frozen Protocol semantics still requires:

1. a new protocol/versioned proposal;
2. material independent adversarial review;
3. Owner approval before activation.
