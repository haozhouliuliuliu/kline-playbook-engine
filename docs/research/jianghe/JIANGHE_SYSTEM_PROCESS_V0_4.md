# 江河交易系统设计/执行/复盘过程 V0.4（001–053）

本文件只整理来源中已经明确出现的“系统如何被构建、执行和复盘”。它不是机器策略，也不补任何来源没有给出的参数。

## 1. 市场信息不是图形因果

- V049：画图、画线、N/W等结构是把K线变化压缩成可识别信息；市场不会因为画了线就照线运行。
- 结构/形态应被拆成背后的信息：哪一方能否继续创新极值、动能是否变化、空间/斜率如何、止损成本多大。
- 因此 `PATTERN_NAME != TRADE_PERMISSION`。

## 2. 系统先设计，盘中只识别条件并执行

V050给出非常明确的架构：

```text
构建阶段：主观地设计交易系统、定义条件与行动预案
盘中阶段：客观地识别市场触发了什么条件
执行阶段：调用对应预案
未触发：不交易
```

这解释了“应变”与“不要盘中灵机一动”并不冲突。应变不是即兴预测，而是根据新信息在既有方案之间切换。

## 3. 交易模式必须明确取舍

V046明确提出胜率、频率、盈亏比不能同时追求极致，并给出三种模式化取舍：

- 偏高胜率 + 高频：接受较低单笔盈亏比，类似超短线/剥头皮；
- 偏高胜率 + 高盈亏比：接受低频、长时间等待；
- 偏高盈亏比 + 高频：接受更多小额试错/止损。

这里记录的是江河的系统设计原则，不把它升级成项目统计学定理。真正可执行的统计口径、窗口和阈值仍 `UNKNOWN`。

## 4. 订单类型在进场前就应决定

V050明确：进场前应知道“拿什么成本换什么利润”。

- 剥头皮信号进入 → 按剥头皮的利润/风险尺度管理；
- 波段信号进入 → 不应因为小级别波动马上把订单当超短线退出；
- 进场后不能因情绪临时把订单从一种类型改成另一种类型。

当前仍缺“剥头皮信号/波段信号”的完整机器分类。

## 5. 风险/结果评价以系统一致性为先

- V049：止损和亏损是中性的风险成本，不自动等于失败。
- V049：“真赢”指按自身体系、在可控风险里取得可复制结果；扛单、梭哈或偶然盈利不能因为赚钱就被视为正确执行。
- V048：环境导致不专注时，来源会主动避免开大仓位；精神状态是风险许可的一部分，但无统一量表。
- V046：主动接受可控损失、放弃模糊机会，是为了让体系闭环、可复制、可执行。

这些内容只用于来源语义，不把视频中的盈利金额当 validity evidence。

## 6. 体系必须适配个人，而不是忠于技术流派

- V049：体系应位于“市场规律 × 交易规则 × 个人诉求”的交集。
- V053：技术流派没有天然高低，只分“适合自己/不适合自己”；不同流派是同一市场的不同观察面。
- V053：可以用结构定义方向、用裸K做微观理解，并针对不同市场调用不同方案。
- 融合的标准是理解底层机制并形成连贯体系，不是把流派标签和表面形态堆在一起。

## 7. 复盘是双层闭环

V051把复盘分成战略和战术两层。

### 战略复盘

```text
目标
→ 实际结果
→ 差距
→ 列举可能原因
→ 深挖到根因
→ 选择解决方案
```

来源示例：如果突破手法在震荡中反复亏损，可以：

1. 学会识别震荡并放弃；
2. 构建震荡专用策略；
3. 如果仍不会分类，就只做自己最标准、最熟悉的机会。

### 战术复盘

订单记录先分开：

- 市场真实状态（截图/客观标记）；
- 当时自己的交易思路/逻辑。

记录完成后再做复盘，动作分为：

- `CONTINUE`
- `IMPROVE`
- `STOP`
- `START`

## 8. 学习方法与认知建设

- V044：认知面积/密度比喻，强调知道很多但不深入不足以形成可调用能力。
- 提高密度的方法是专注并深入。
- V053：模仿 → 适配/融合 → 自己的智慧。
