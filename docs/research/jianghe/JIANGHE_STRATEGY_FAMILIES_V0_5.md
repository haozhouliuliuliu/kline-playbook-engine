# 江河交易员策略家族规格 V0.5（001–063）

本文件是来源化研究规格，不是机器策略或交易授权。核心 Family 仍只有 A–D。`UNKNOWN` 不得自行补参数。

## JH-FAMILY-A：趋势关键位回调延续

| 字段 | 当前来源化规格 |
|---|---|
| applicable_market | 已识别趋势/突破后的延续环境；弱趋势更适合回调，强推动后也可等第一段浅弱回调 |
| preconditions | 方向偏向明确；原推动强度足够；反向回调应相对浅弱，不能快速深度否定原推动 |
| location | 趋势防守/发力位、上涨/下跌起始区域、内部N回调区 |
| trigger | 二推失败、结构修复、顺向确认K、吞没；V054要求防守位不失守后向上确认；V059使用二推不破 |
| no_trade | 回调过深/加速、关键位失守、前方空间太近、只有长针无确认、追价导致止损过宽 |
| stop_or_invalidation | 回调/入场结构极值外；防守位有效失守则取消 |
| management / exit | 趋势有效则跟随；弱趋势/横向背景可使用前高/前低实体参考目标；二推失败、强反向K、动能降级时保护利润 |
| position_risk | 有双周期共振为质量加分；无共振但单周期条件完整仍可做，来源显示应轻仓；低评分可0.5×；加仓必须有新独立条件 |
| timeframes | 1H→5m反复出现；也允许5m独立周期模式 |
| explicit_numeric_rules | 既有ABC数字；V055低评分0.5×；V061两次0.5×尝试合计约一笔常规风险语境 |
| human_discretion_fields | 浅/深回调、关键区边界、剩余空间、确认K质量、前高实体参考区选择 |
| unknown_fields | 独立周期轻仓精确倍数、统一账户风险、统一回调深度阈值 |

## JH-FAMILY-B：趋势衰弱反转 / 高周期回调

| 字段 | 当前来源化规格 |
|---|---|
| applicable_market | 原趋势末期/衰弱、高周期关键区，或出现特别强的反向推动但完整新趋势尚未完全形成 |
| preconditions | 原方向无法继续创新极值/动能衰弱；或V055式强反向推动足以形成方向偏向，但需小周期确认 |
| location | 原趋势防守位、显著高低点、高周期高价值区域、回抽结束区域 |
| trigger | 低周期二推失败、盘整破位、反抽失败、强反向K；V055为强1H下跌背景+5m二推不破空 |
| no_trade | 只破一个发力点就当完整趋势；逆强主趋势直接猜顶底；破位后追价导致RR恶化 |
| stop_or_invalidation | 结构另一侧；原方向重新强势延续则否定反转假设 |
| management / exit | 动能减弱与目标区结合；强转弱时降低盈利预期 |
| position_risk | V055低评分/非标准模型明确0.5×平时仓位；完整家族统一算法仍UNKNOWN |
| timeframes | 高周期背景 + 小周期转折；也存在5m独立转折语境 |
| explicit_numeric_rules | 低评分案例0.5×；不升级为所有B订单固定仓位 |
| human_discretion_fields | 强反向动能是否“足够强”、二推质量、回抽结束点、目标区域 |
| unknown_fields | 提前抓转折的强动能阈值、统一风险模型 |

## JH-FAMILY-C：多周期确认突破

| 字段 | 当前来源化规格 |
|---|---|
| applicable_market | 强趋势或大结构/区间的真实突破 |
| preconditions | 突破前方结构/空间；离开旧空间；强推进与同向跟随；之后反向回调最好浅弱、不重新深度进入旧空间 |
| location | 大结构/震荡边界、突破后回踩区、内部防守/发力位 |
| trigger | 强突破+跟随后的小周期浅回调结束、二推失败、顺向吞没/确认K |
| no_trade | 只有影线刺破、未离开旧空间、无跟随、回调过深、前方阻力过近、直接追价令风险恶化 |
| stop_or_invalidation | 突破结构失效或防守位被有效破坏；重新深度进入旧空间是减分/失效证据 |
| management / exit | 新内部结构形成可推进止损；目标位无排斥且继续跟随则持有；二推失败/动能降级可退出 |
| position_risk | 高低周期共振加分；无共振并非绝对禁止，但来源将独立周期订单质量下调/轻仓；有减分项可0.5× |
| timeframes | 1H→5m为主实例；既有4H+15m、15m+1m推荐组合继续有效 |
| explicit_numeric_rules | 仍无统一突破距离/跟随强度阈值；低评分/减分项0.5×只在特定来源语境明确 |
| human_discretion_fields | “拉开足够距离”、跟随质量、回调浅弱程度、前方空间 |
| unknown_fields | 距离阈值、跟随阈值、独立周期仓位倍率 |

## JH-FAMILY-D：震荡边界反转

| 字段 | 当前来源化规格 |
|---|---|
| applicable_market | 已确认震荡/宽幅震荡。V058/V063强化：双向均能创新极值，但两边缺乏持续跟随、快速收回；暴跌暴涨并存也可构成宽幅震荡 |
| preconditions | 只在上下边界优先；到位后必须继续观察推动衰弱/排斥/吞没等确认 |
| location | 震荡上沿/下沿；中间区域不做 |
| trigger | 二推/多推失败、长影排斥后再等吞没、饱满反向实体K；V063明确长下影本身仍不足，后续大阳吞没才进多 |
| no_trade | 区间中间；只有到位/长影无确认；成功真突破后仍坚持反转 |
| stop_or_invalidation | 结构另一侧；真突破后停止D并重新分类 |
| management / exit | 可预设区间/实体参考目标，也可动态；多次向目标方向尝试却缺乏跟随时可谨慎退出 |
| position_risk | V021 0.5×常规仓位仍保留；无多周期共振的独立5m震荡单允许存在，但精确仓位修正未统一 |
| timeframes | 高周期可提供区间背景；V058证明5m独立周期也可形成完整D交易 |
| explicit_numeric_rules | `0.5 × REGULAR_POSITION_SIZE`仍只在特定source-version明确；案例1:2/1:3/不足1:1均不升级为规则 |
| human_discretion_fields | 区间边界、排斥/吞没质量、真突破判断、前高实体目标位置 |
| unknown_fields | 震荡分类机器阈值、统一止盈、独立周期风险修正 |

## Family 间与质量层切换

- `BIAS_DIRECTION` 是过滤层：V054明确，多头偏向下并非所有多信号都做，但空信号直接过滤。
- D 真突破后可切 C；C/A 强趋势回调过深后可失去延续许可。
- 多周期共振是质量加分项，不是所有Family统一硬门槛。V058/V060明确允许 `SINGLE_TIMEFRAME_MODE`，但V060将其视为低质量并轻仓。
- 低评分/有减分项可以通过仓位下调而不是强行二元化为“做/不做”；V055/V061均出现0.5×。
- 止损后若有全新独立条件可重进；V061进一步表明两个0.5×尝试可合计控制在一笔常规风险语境。

## AUXILIARY_TOOL_USAGE：均线

V061原视频明确说重进场时“触碰到了这根均线”，图表也可见均线。当前仅登记为辅助证据：

```text
STATUS=AUXILIARY_TOOL_USAGE
CORE_FAMILY=NO
REQUIRED_INDICATOR=UNKNOWN
PARAMETERS=UNKNOWN
```

V056反对的是把指标/量化/跟单当作不劳而获的稳定盈利捷径，不能据此推导“任何指标永远禁止”。因此当前不把V061均线辅助视为对核心裸K/结构框架的直接否定，也不把它升级为新策略Family。

## NON-FAMILY：SCALPING_EXECUTION_MODE

V040/V043的非核心剥头皮定位保持不变，不创建Family E。
