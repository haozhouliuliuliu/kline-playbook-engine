## 可恢复并行下载器与网络诊断

新增通用 HTTP Range 下载器，使用 16 MiB 分块、并发 4、每块有限重试。它严格要求 `206` 与精确的 `Content-Range`，只复用长度和 SHA-256 都匹配的完整分块；任一分块缺失、篡改或总长度不符时拒绝拼装候选文件。临时状态不记录完整下载地址或查询参数。

本轮在同一路由下的实测结果（均包含卡住等待）为：

```text

BILIBILI_COMPLETED_BYTES=18623712
BILIBILI_OBSERVED_THROUGHPUT_MBPS_APPROX=0.03
BILIBILI_FAILURE=ONE_MID_FILE_RANGE_REQUEST_STALLED_AFTER_FINITE_RETRY_WINDOW

HF_OBSERVED_THROUGHPUT_MBPS_APPROX=0.33
```

007 的已有损坏正式文件没有移动；没有产生完整视频和音频，因此没有执行 mux、ffprobe、完整解码或隔离替换。已验证的分块仅保留在仓库外修复目录，供下一次使用同一工具续传。

Hugging Face 官方 API、模型元数据以及配置、词表等小文件均可访问。官方 `model.bin` 的 LFS SHA-256 与总长度已取得用于完成后校验；大文件尚未完整拼装，故没有运行 CTranslate2 加载，也没有开始 065 pilot 或 016、017、018 的转写。

现有四个 Sol review package 保持为无伪造转写的状态；没有复制视频或写入不完整 ASR。`whisper.cpp` 仍仅为备用 `CANDIDATE`，未作为第二个生产方案启用。
