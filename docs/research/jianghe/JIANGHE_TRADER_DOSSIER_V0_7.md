## 1. 市场分类体系

核心仍是 **趋势 / 震荡**，并区分方向、强弱、初期/末期、延续/衰弱/反转；宽幅震荡可同时容纳内部弱多/弱空偏向。

V075/V078把强弱市场进一步统一为“市场节奏”：强势/失衡市场接近直线推进、趋势型K较多、回调很浅或几乎没有，较适合突破；弱趋势回调更深、创新极值后拉不开空间且缺少跟随，较适合回调交易。

V078正式给出另一组来源术语：`平衡 = 震荡价值区`、`失衡 = 价格脱离旧价值区的方向运动`。V079继续用发力点数量和间距描述稳定度：发力点少且间距远代表分歧少/掌控力度更强；密集发力点代表分歧增多、行情更不稳定。

## 2. 各行情前置条件

稳定链条仍为：

```text
外部市场状态
→ 方向/节奏
→ 关键位置与剩余空间
→ 动能与强弱变化
→ 低周期/当下确认
→ 执行
```

V075明确“手法不能脱离市场节奏”：强势市场优先突破，弱趋势优先回调。V078把这一思想写成“历史只给参考、当下反应才决定是否执行”。V082再次用学习/系统链明确：趋势、关键位、信号、止损、仓位、止盈、RR必须被串成连贯逻辑，而不是零散技术点。

## 3. 关键位置及形成

既有位置继续包括波段起止、历史高低点、发力点、防守位、震荡边界、突破区域、交易位/参考位。

V079进一步正式定义发力点：强弱转换后引起一段推动的转换/博弈位置，是潜在二次攻防点，也可起支撑阻力作用；但**发力点绝不能单独成为开单理由**。

V077/V081继续用“弱空最后发力点”作为高空位置；V079上涨案例则用持续上移的多头发力点作为回调低多位置。

## 4. 关键位置上的价格/K线行为

核心观察继续为创新极值、跟随、排斥、吞没、强/弱趋势K、影线、回调强弱、二推/多推、防守破坏。

V078把K线强弱正式展开：

- 实体占整根K线50%以上 → `趋势型K线`；
- 影线占整根K线50%以上 → `非趋势型K线`；
- 强弱必须相对左侧K线比较整体大小、实体大小、影线大小；
- 重要的是连续K线的变化过程，而不是单根K线。

V078/V079同时正式化 `强-弱-强`、`原方向强→弱/新方向增强`、`对抗态` 等行为。若中间逆向K并不弱，则不能硬套“强弱强”。

## 5. 入场时机与触发

核心仍只有四个 Family A–D。

本批新增/补强：

- V074：弱空5m逻辑 → 发力/防守位 → 1m只优化进场。
- V077：1H宽震荡/弱空共享上方许可 → 5m真实转折与弱空发力位 → 空；另有5m宽震荡下区 → 1m空头减弱/多头增强 → 左侧多。
- V079：原趋势发力点持续移动 → 回到关键发力点 → 逆向K从趋势型变非趋势型/减弱 → 顺向强K否认 → 收K进入。
- V081：5m弱空只做高空，最后空头发力点定位置；1m多头强转弱 + 空头发力后做空。

V078明确：若出现 `对抗态`（旧方向未减弱、新方向也很强），双方未分胜负时不入场；可以等第二次博弈结果。

## 6. 明确不交易条件

累计硬边界继续增加：

- 关键位无当下确认不做；
- 震荡中间不做主周期边界单；
- 弱趋势不追突破/追价；
- 强趋势中死等不存在的深回调可能错过，但不能因此降低其他必要条件；
- 发力点到位本身不构成开单理由；
- 单根K、N/W形态、画线本身不构成交易理由；
- `强-弱-强`中间逆向K不弱时不做；
- 对抗态未分胜负时不做；
- 偏向是过滤器，不是自动触发器；
- 回成本区没有新独立信号不加仓；
- 系统外机会即使事后走很远，也不能临时追。

## 7. 如何承认判断错误

逻辑/结构止损仍是主框架。

V079正式给出“以损定仓”并反复以近期高低点/结构另一侧作为案例止损。其课件中同时出现一句“若近期高低点就是进场K，也会把止损放当下K线收盘价”，但同页图示及后续案例仍画在极值外，因此这句当前保留为 `SOURCE_INTERNAL_TEXT_VISUAL_CONFLICT`，不升级规则。

V083继续提供 hard negative：无止损、重仓梭哈后一次暴赚不能因为结果好就被视为正确可复制执行。

## 8. 盈利后的持仓管理

固定RR、固定目标区域、动态结构退出继续并存，且必须与**进场前订单类型**一致。

V074再次确认本人主战场仍是日内波段/微波段；微波段可不预设固定止盈。V081弱空微波段则使用下方前低/多头发力点作为有限空间目标。

V080正式钉死“卖飞”的评价原则：是否退出错误不能看事后行情走多远，而要看进场前计划。剥头皮按短线尺度退出后行情继续飞不算错；趋势单若只因微小波动提前离场才属于执行偏离。

## 9. 仓位与风险流程

风险母规则明显补强。

V078把交易描述为概率/风险经营，并列出胜率、盈亏比、频率三项经营指标。V079给出可直接机器表达的以损定仓公式：

```text
position_size = acceptable_loss / (stop_distance × value_per_point)
```

先固定可承受亏损，再根据止损距离和每点价值调整仓位/杠杆。V079中的2%和1%均是教学示例，**不是统一永久账户风险参数**。

V081给出另一个重要边界：原计划10手拆成两笔5手只是 `ENTRY_SPLIT`，不是因为第一笔后又新增风险的“加仓”。

统一账户风险比例、各Family质量折扣、加仓比例仍 `UNKNOWN`。

## 10. 多周期协调

既有 `4H+15m / 1H+5m / 15m+1m` 与单周期降级模式继续成立。

V078从底层定义时间周期：不同周期是同一价格过程的不同聚合呈现；大周期K可在小周期展开成趋势/震荡，小周期结构也构成大周期K的内部过程。

V074/V077/V081继续出现 `5m→1m`：主周期定方向/位置，小周期只做精细触发或更优点位。该关系不能反过来把小周期内部噪音升级成主周期趋势结论。

## 12. Lookalike / Hard Negative

新增重要反例：

- 发力点=潜在攻防位置，但 `发力点 != 自动开仓`；
- 单根强K、N/W、趋势线等是信息载体，不是市场原因；
- 原方向强、新方向也强 = 对抗态，不是立即反转信号；
- 中间回调K不弱，则不是强弱强；
- 弱空仍做空，但不等于任何位置都能空，应高空而不是追空；
- 同一计划分批打入 ≠ 风险意义上的加仓；
- 剥头皮按原计划离场后行情继续走远 ≠ 卖飞错误；
- 无止损/梭哈一次暴赚 ≠ 可复制正确策略。

## 13. 明确规则 vs 主观判断

### DIRECTLY_PROGRAMMABLE

- 趋势型K / 非趋势型K 50%来源定义；
- `PATTERN_NAME != TRADE_PERMISSION`；
- 以损定仓公式；
- 进场前订单类型决定退出评价；
- `ENTRY_SPLIT != ADDITIONAL_RISK_ADD`；
- 系统执行链：趋势→位置→信号→失效止损→按止损算仓→空间/目标→RR；
- 无止损/梭哈结果盈利不能升级为正确执行。

### MULTI_CASE_INFERABLE

- 强/弱趋势与市场节奏；
- 发力点数量/距离体现分歧和稳定度；
- 强-弱-强；
- 原方向强转弱/新方向增强；
- 对抗态及二次博弈；
- 平衡/失衡分类。

### HUMAN_DISCRETION_REQUIRED

- “接近直线”到底多直；
- 浅/深回调；
- 发力点精确选取；
- 强弱K相对比较；
- 对抗态何时真正分出胜负；
- 订单模式与个人适配性。

### NOT_YET_UNDERSTOOD

- 50%恰好等于边界时的唯一分类；
- 发力点间距/数量的统一量化阈值；
- K线强弱的统一机器标准；
- V079“进场K收盘价止损”文本与图示冲突；
- 统一账户风险比例；
- V083“70%技术/30%人”只能保留来源修辞，不能作为算法权重。

V078还正式解决了“裸K vs 均线”的表面冲突：江河明确说指标只是辅助而非决策依据，并明确自己有时会使用均线。因此均线继续是 `AUXILIARY_TOOL_USAGE`，不构成新Family。

## 14. 独立策略家族

核心仍只有：

- `JH-FAMILY-A` 趋势关键位回调延续；
- `JH-FAMILY-B` 趋势衰弱反转 / 高周期回调；
- `JH-FAMILY-C` 多周期确认突破；
- `JH-FAMILY-D` 震荡边界反转。

V075/V078/V079进一步说明A/C不是两套脱离环境的固定图形，而是要由**市场节奏/平衡失衡/发力点变化**选择。V074再次明确江河本人核心日常交易仍是日内波段/微波段；`SCALPING_EXECUTION_MODE` 保持非核心执行模式。

本版本未访问 outcome/validation/final，`SOURCE_ONLY_VERIFIED=NO`，仍不是 PRIMARY-ready。
