## 1. 市场分类体系

核心仍是 **趋势 / 震荡**。趋势继续区分方向、强弱、初期/末期、延续/衰弱/反转；震荡包含规则、宽幅、不规则/扩散、压缩等表现。

V066/V067/V069再次独立确认宽幅震荡：价格能够向上创新高、也能向下创新低，但两个方向都缺乏结构性延续/跟随，或突破后快速收回。

V069新增重要层级：**同一周期的内部结构与外部结构必须分开。** 内部结构只能帮助确认本周期的外部结构；不能把本周期内部结构直接当成本周期波段交易许可，也不能把它冒充成下一小周期的外部结构。

V069还确认：外部可仍是宽幅震荡，但内部低点不断抬高，形成弱多偏向。市场分类与内部方向偏向可以同时存在。

## 2. 各行情前置条件

累计主链保持：

```text
市场环境/外部结构
→ 方向偏向与动能
→ 关键位置/剩余空间
→ 低周期真实行为
→ 触发
→ 执行
```

V069进一步区分：`外部市场状态` 决定波段许可，`内部结构`主要用于解释/确认外部状态；若想交易更小波动，应切到更小周期重新识别其外部结构。

宽幅震荡只做边界高空低多；若内部为弱多，则不追多、不做空，优先等下半部低多并观察空头强转弱+多头发力。

V068继续强化“转弱不等于完成触发”：原方向减弱后，新方向还应出现足够跟随/爆发，否则可先退出等待。

## 3. 关键位置及形成

已确认位置继续包括：波段起止、历史显著高低点、趋势防守位、发力点、震荡边界、突破后区域、交易位/参考位。

V066/V069把宽幅震荡的外部波段关键位进一步钉死为上方最高点区域与下方最低点区域。波段角度的中间内部波动不自动成为高价值交易位。

V068继续确认：5m前方高点可以作为关键节点，但只负责把注意力集中到位置，最终要在1m看实际行为。

## 4. 关键位置上的价格/K线行为

累计观察项包括：创新极值、跟随、排斥、吞没、强趋势K、影线、回调强弱、二推/多推失败、防守破坏、斜率/速度变化。

V067给出更具体的弱回调视觉链：**反向K实体逐步减小 + 影线占比增大 → 反向动能减弱；随后顺向K实体增大 → 顺向力量介入。**

V066/V068继续把“动能/斜率是否继续”用于持仓和重入：下跌斜率由陡变缓可提前退出；多头减弱后若空头没有真正爆发/加速，则触发质量不足。

## 5. 入场时机与触发

核心仍为四个 Family A–D。

本批新增/加强：

- V066：宽幅震荡上沿 → 向下打破 → 反抽不能创新高/二推失败 → 空。
- V067：外部宽幅震荡中的内部压缩向上突破 → 回调空方实体缩小/影线增加 → 顺向阳线增强收K → 多。
- V068：5m关键点 → 1m多头减弱 → 等空头真实爆发/加速；第一轮没有跟随可退出，第二轮出现爆发才再参与。
- V069：弱多宽幅震荡 → 下半部区域 → 空头强转弱 + 多头发力 → 低多。
- V073：1m震荡下沿再次测试不破 → 向上收回 → 减弱/加速转换 → 剥头皮多。

## 6. 明确不交易条件

累计边界进一步增加：

- 宽幅震荡波段中间区域不做主周期波段单；
- **不能拿本周期内部结构直接作为交易机会；**
- **不能把本周期内部结构当作小周期外部结构；**
- 弱多背景不做空，也不追多；
- 转弱后新方向没有爆发/跟随，不急着做；
- 接近震荡另一边界后不继续追同方向短线；
- 系统未触发时，不在盘中为想做的订单找新理由；
- 同样市场不能因情绪任意改变方向和仓位。

## 7. 如何承认判断错误

核心仍是逻辑止损、结构另一侧止损与市场对原假设的否认。

V066空单止损放在外部上方高点外；V067多单止损放下方结构；V073震荡多若下沿真实突破则原逻辑失效。

V070继续强调：盘中触发预设离场条件就离场，不能在已有离场条件出现后临时找理由继续持有。

## 8. 盈利后的持仓管理

固定RR、固定空间、动态结构三类退出继续并存，江河本人仍偏动态。

V066进一步体现 Family D 的保守管理：宽幅震荡不追求“格局”，即使第二目标尚未到达，只要运动斜率由陡转缓，也可以提前退出。

V067前高处二推不破/动能减弱即敏感退出。

V073再次把“订单模式一致性”钉死：剥头皮单必须按剥头皮尺度管理；微波段单必须按微波段目标管理。事后价格继续上涨，不能倒推原剥头皮退出是错误。

## 9. 仓位与风险流程

既有控制最大损失、止损宽减仓、震荡0.5×、ABC分份、评分仓位、左侧/无共振轻仓等保持。

V064新增非常简短但明确的风险观：正确方向不是逃避风险，也不是无视风险，而是**理解并计算风险/盈亏比**。没有给统一RR阈值。

V070继续强化仓位一致性：同样市场不能因为当天心情不同而一会重仓、一会轻仓，否则无法保持可重复行为。

V072新增周期相关风险/成本维度：过小周期可能提高交易成本、交易频率和状态负担，从而导致执行变形；更大周期可能缓解这些问题，但周期本身不是edge。

## 10. 多周期协调

既有推荐 `4H+15m / 1H+5m / 15m+1m` 保持。

V067新增“外部边界用5m主周期逻辑、外部中间可切1m做非核心剥头皮”的位置驱动模式切换。

V068继续使用 `5m关键点 → 1m真实行为`。

V069最重要的新边界是：**同周期内部结构不等于下一小周期外部结构。** 若要用1m交易，就切到1m重新识别1m自己的外部结构。

V072从聚合角度解释：同一品种不同周期呈现的是同一价格过程；小周期趋势可以被理解为大周期K线的内部展开，但不能据此把结构身份直接跨周期搬运。

## 11. 成功、失败与复盘案例

本批新增正式案例：

- V066 宽幅震荡上沿二推失败空；
- V067 外部宽幅震荡中的内部压缩突破多，并在前高二推失败退出；
- V068 5m关键点下1m转弱空，第一轮无爆发退出，后续有爆发才再参与；
- V073 1m宽幅震荡下沿剥头皮多，并用后续继续上涨作为“不能事后改写订单模式”的反例。

V071再次补强复盘流程：每天约两小时，不是证明判断正确，而是检查动作是否变形——该等有没有等、该砍有没有砍、是否因贪婪多拿、因恐惧提前跑。

V065当前只有MP4、没有SRT且抽样无稳定烧录语义字幕，因此不从纯视觉订单结果反推策略逻辑，等待本地ASR或直接音频复核。

## 12. Lookalike / Hard Negative

新增重要反例：

- 本周期内部结构 ≠ 本周期独立交易机会；
- 本周期内部结构 ≠ 小周期外部结构；
- 外部宽幅震荡 ≠ 内部完全没有方向偏向；
- 弱多 ≠ 追多；弱多也 ≠ 做空；
- 多头减弱 ≠ 空头已经形成足够触发；
- 宽幅震荡的第二目标未到 ≠ 一定要死拿；
- 剥头皮单事后继续上涨 ≠ 原退出“卖飞”；
- 小周期短期样本更差 ≠ 小周期本身导致亏损；
- 盘中给订单不断找新理由 ≠ 深度分析。

## 13. 明确规则 vs 主观判断

### DIRECTLY_PROGRAMMABLE / 流程级

- 系统触发进场条件→进；触发离场条件→离；
- 同一周期内部结构不得直接标记为小周期外部结构；
- 盘中不得临场改变交易系统定义；
- 订单类型/尺度必须与进场前定义一致；
- 不同样本量不能直接比较胜率优劣。

### MULTI_CASE_INFERABLE

- 宽幅震荡双向无延续；
- 外部震荡中的内部偏向；
- 弱回调实体缩小/影线增加；
- 新方向爆发/加速；
- 周期/位置驱动的执行模式切换。

### HUMAN_DISCRETION_REQUIRED

- 内外结构具体划分；
- 二推失败质量；
- “爆发/加速”强度；
- 斜率由陡变缓的阈值；
- 外部中间区域何时适合剥头皮；
- 震荡内部弱多/弱空偏向质量。

### NOT_YET_UNDERSTOOD

- 统一账户风险比例；
- 完整评分公式；
- 内/外结构机器算法；
- 跨周期聚合与结构映射的精确规则；
- 周期选择与交易成本/状态的量化优化；
- 无SRT Video 065的完整语义。

## 14. 独立策略家族

核心仍只有：

- `JH-FAMILY-A` 趋势关键位回调延续；
- `JH-FAMILY-B` 趋势衰弱反转 / 高周期回调；
- `JH-FAMILY-C` 多周期确认突破；
- `JH-FAMILY-D` 震荡边界反转。

本批没有创建 Family E。

V067/V073继续证明 `SCALPING_EXECUTION_MODE` 可以嵌在A/B/C/D的市场逻辑中，但其区别主要是订单尺度、目标和持有方式，而不是第五类核心市场机制。

V069的均线再次只作为 `AUXILIARY_TOOL_USAGE`：帮助观察震荡中的上下缠绕，不构成独立Family或必需入场条件。
