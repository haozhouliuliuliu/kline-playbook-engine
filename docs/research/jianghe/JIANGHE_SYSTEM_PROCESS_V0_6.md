# 江河交易系统设计/执行/复盘过程 V0.6（001–073）

本文件只整理来源已经明确出现的系统构建、盘中执行、风险和复盘过程，不补来源没有给出的参数。

## 1. 构建、盘中执行、复盘三阶段

V050/V070共同把流程钉死：

```text
系统构建/盘前：主观设计条件、预案、风险、订单模式
盘中：客观识别是否触发既有条件，并执行
盘后：用数据与记录检查执行和系统缺口
```

V070所谓“盘中不要分析”是指不要临场为想做的订单找理由、改变方向或仓位；并不等于不读取市场。V042/V050已经说明盘中仍要识别新信息并在既有预案之间切换。

## 2. 外部结构优先，内部结构只做解释/确认

V069新增非常明确的结构治理：

```text
同周期外部结构 = 当前波段/市场状态的主要决策层
同周期内部结构 = 帮助确认外部结构
同周期内部结构 != 下一小周期外部结构
```

如果5m外部是宽幅震荡，5m内部波动不能直接拿来做5m波段单。若想交易中间的小波动，应切到1m重新识别1m自己的外部结构。

这条边界对后续机器化非常重要：不能通过图形嵌套自动把“内部N”提升成另一个周期的可交易外部N。

## 3. 偏向是过滤器，不是触发器

V054已明确；V069继续补充震荡中的内部偏向：

- 外部宽幅震荡；
- 内部低点持续抬高；
- 可标记为弱多偏向；
- 弱多不追多、不做空；
- 优先等下半部出现空头强转弱+多头发力。

因此：

```text
BIAS = DIRECTION_FILTER
BIAS != ENTRY_TRIGGER
```

## 4. 模式与位置共同决定使用哪个周期

V067明确：外部宽幅震荡的上下高价值边界可使用5m主周期逻辑；在外部中间区域，如果一定要参与，则切1m按剥头皮模式重新识别1m结构。

这不是把5m内部结构直接做成1m，而是重新在1m上建模。

## 5. 转弱之后仍要新方向跟随

V067/V068进一步把“强转弱”拆成两段：

```text
旧方向实体/斜率变弱
→ 新方向介入
→ 最好出现更清楚的跟随/爆发/加速
```

旧方向减弱本身不是完整反向触发。V068第一轮空头没有爆发时可先退出，后续新爆发再作为新机会。

## 6. 风险是被计算和限制的成本

V064用极短视频强调：躲避风险和无视风险都不是其主张；成熟处理是理解风险并计算盈亏比。

既有来源继续支持：固定最大损失思想、止损宽减仓、不同Family/评分/共振修正仓位。V070还把“同样市场今天重仓、明天轻仓”列为不一致行为。

## 7. 订单模式在进场前定义，事后结果不能重写

V050/V073共同形成清楚规则：

```text
进场前定义订单类型
→ 对应风险/利润尺度
→ 对应退出条件
→ 持仓期间保持模式一致
```

剥头皮单按剥头皮尺度退出；微波段单按微波段目标管理。事后价格继续运行，不代表原剥头皮退出错误。

## 8. 周期不是edge，但会改变成本、样本和执行状态

V072明确：不同周期是同一价格过程的不同聚合；换周期不能替代交易逻辑。

周期会影响：

- 交易次数/样本累积速度；
- 交易成本；
- 时间成本；
- 机会成本；
- 交易者状态与执行变形概率。

因此周期选择更像系统适配/成本优化，而不是独立盈利来源。

## 9. 样本量必须进入概率解释

V072用10笔80%与100笔20%的教学例子说明：不同样本量的短期胜率不能直接比较并得出“哪个周期更好”。小样本随机性可能掩盖真实概率。

这些数字是教学例子，不是江河系统真实统计，也不是本项目validity evidence。

## 10. 复盘继续以过程一致性为主

V071明确每天约两小时复盘，重点检查：

- 该等的机会有没有等；
- 该砍的订单有没有砍；
- 是否因贪婪多拿；
- 是否因恐惧提前跑；
- 交易动作是否变形。

“两小时”只记录为个人习惯，不升级为普遍规则。
