# 江河交易系统设计 / 执行 / 风险 / 复盘过程 V1.0

本文件只整理来源明确出现的跨Family过程规则，不补参数。

## 1. 系统先限制交易

技术与系统的作用首先是减少不属于自己模式的交易，而不是覆盖所有行情。系统条件未满足时不执行。

## 2. 决策层级：势 → 位 → 态 → 真实触发

V007明确给出交易考虑顺序：趋势/势最重要，位置其次，形态最后。累计证据再加上低周期触发后，当前过程可写为：

`市场状态/趋势 -> 方向偏向 -> 位置/空间 -> 强弱变化 -> 实际低周期行为 -> 触发`

任何单层都不能静默升级成完整交易许可。

## 3. 多空条件独立

`LONG_INVALID != SHORT_VALID`。一个方向不成立，不自动生成反方向许可。

## 4. 位置是过滤器，不是触发器

V018/V088等反复说明：到关键区只意味着进入观察区；必须等待真实反应、企稳、转向或低周期触发。

## 5. 内部结构的角色边界

V069明确：同周期内部结构只能帮助确认外部结构，不独立提供交易机会/交易逻辑。V018和后续材料支持其用于弱化判断、重分类、管理和防守参考。

若要使用低周期结构，必须切换到该低周期并重新识别其自己的结构。

## 6. 盘前设计与盘中应变

盘前/系统构建阶段定义情景与条件。盘中允许根据客观新信息切换已经存在的方案，但不能因为想开单而临时发明理由。

## 7. 退出必须预先属于某种方法

V017固定三种来源有效方法：
- 固定R/R；
- 关键位置/空间；
- 动态市场结构。

来源本人偏动态，但不把三者排成绝对优劣。动态退出应预先定义“什么市场条件会否认入场逻辑”。

## 8. 趋势阶段影响退出

V017明确：
- 趋势初期可用更右侧退出，让利润发展；
- 非初期可更早/左侧退出，降低风险。

这关闭了“初期 vs 非初期退出是否矛盾”的语义问题；跨案例统一机器判定仍未完成。

## 9. 风险先于收益

正常亏损属于经营成本；违规亏损属于执行罚款。不能追求零亏损。

最明确仓位关系仍是给定可接受损失与止损距离后的以损定仓。来源中的账户百分比/美元示例不得自动升级为统一参数。

## 10. 质量影响风险预算

评分、共振、左/右侧、市场状态、个人状态都反复作为仓位质量修正项。V099直接强化：
- 高质量订单可分配更多风险预算；
- 低质量订单少分配；
- 小资金不需要另一套独立交易策略，核心仍是交易逻辑与风险分配。

但一个跨Family、跨状态的完整母公式仍未被来源给出。

## 11. 账户层事前风控

V094：设置当日最大可动用交易资金/额度，减少“上头”后继续扩张风险的机会。

V099：只在交易账户保留需要的资金，剩余资金可物理隔离；目的包括尾部风险控制和避免余额放大人性问题。

具体额度、重置规则、与单笔风险公式的统一关系仍 `UNKNOWN`。

## 12. 账户P&L不能替代市场事实

V096三个维度显示：最差状态是按账户盈亏变化做交易；中间状态是账户盈亏与真实行情同时驱动、产生内耗；目标状态是只按K线/市场节奏执行，不跟情绪和账户余额走。

## 13. 个人状态是风险输入

V048直接说明外出环境导致不专注，所以不敢开太大仓位；V084/V090也显示状态会影响参与、仓位、新增风险、持仓时间和退出方式。量化状态表仍未知。

## 14. 复盘分离结果与过程

盈利不证明执行正确，亏损不证明执行错误。来源案例的利润、R和账户金额只能用于理解当时案例，不作为项目策略有效性证据。

## 15. ASR只能运输证据，不能自动成为证据

V065证明：
`模型/哈希/时间轴通过 != 语义通过`。

本地ASR要进入语言证据层，必须额外通过源语言与语义合理性抽检；明显重复幻觉、错语言或与音频不一致时必须拒绝，且不得据订单结果倒推口述逻辑。

## 16. 当前仍未机器锁定

- 势位态动四维完整边界；
- 关键区、内部/外部结构、强弱、爆发、二推等视觉算法；
- V030三分开仓边界与完整评分公式；
- V078严格50/50分类；
- V079收盘价止损真实语义；
- 跨Family统一账户风险母规则；
- 状态量表与仓位/管理映射；
- V065可靠语言语义。
