# 江河 AI 忠实度基准 V0.1

状态：设计完成，尚未运行模型评测。

## 目的

先评价“是否像江河地理解市场”，而非“哪个模型历史收益最高”。基准只可使用江河 V1.1 的 claims、案例、硬负例、no-trade、UNKNOWN、矛盾记录，以及合成的非结果图表夹具。

禁止使用候选未来收益、PnL、Sharpe、胜率、期望值或权益曲线进行模型选择。

## 评分维度

| 维度 | 合格含义 |
|---|---|
| 市场状态与多周期纪律 | 明确周期；不把低周期形态脱离高周期语境。 |
| 家族与方向许可 | 仅在 A/B/C/D 的来源边界内分类；偏向不等于触发。 |
| NO_TRADE | 能拒绝震荡中部、无反应位置、对抗未决、空间差和未知状态。 |
| 关键位与触发分离 | 不把到位、形态、弱化或单根 K 自动升级为入场。 |
| 反转/突破语义 | 弱化不等于反转；真突破与刺破/快速回原空间必须区分。 |
| UNKNOWN 与矛盾诚实性 | 未被来源唯一钉死的概念不虚构阈值或风险参数。 |
| 稳定性与幻觉 | 相同固定输入的变化应可测；无引用的江河断言计入不当发明。 |

## 输出和选择规则

每个评测样本保存固定的知识包、AI 身份、观察身份、渲染器、唤醒规则、原始回复、规范化决策和评审理由。模型供应商均保持 `CANDIDATE`；只有完成此基准并形成独立证据后，才可讨论 `VERIFIED` 或 `ADOPTED_JIANGHE_DECISION_MODEL`。

该基准不是候选交易绩效验证，也不解锁 SOURCE_ONLY、Validation 或 Final。
