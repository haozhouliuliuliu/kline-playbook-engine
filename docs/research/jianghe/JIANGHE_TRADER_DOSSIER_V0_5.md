## 1. 市场分类体系

基础仍是 **趋势 / 震荡**。趋势包含方向、强弱、初期/末期、延续/衰弱/反转；震荡包含规则、宽幅、不规则/扩散、压缩等表现。

V055再次明确：标准下跌趋势不是“打破一个发力点”就成立，而是高点持续降低、低点持续降低。局部结构破坏与完整趋势延续必须分开。

V058/V063进一步稳定宽幅震荡语义：市场可以先创新高、再创新低，或反过来，但两边突破都缺乏持续跟随、快速收回；暴跌和暴涨同时出现且双向均能创新极值，也可被理解为宽幅震荡。

V062继续证明结构层级可以重叠：更大空头背景未被彻底否定时，内部多空结构连续互相破坏而均无延续，可重新分类为宽幅震荡；若不同合理分类给出同方向许可，可以保留重叠解释而不强制唯一标签。

## 2. 各行情前置条件

总体链条继续稳定为：

```text
市场环境/交易偏向
→ 动能与节奏
→ 关键位置/剩余空间
→ 低周期行为确认
→ 执行
```

V054/V059强化强趋势/突破后的延续前提：第一推动强、突破有跟随并离开旧空间，之后希望看到 **浅、弱、不能快速否定原推进的回调**。回调过深或继续加速，即使后面出现表面入场信号也可直接放弃。

V055增加例外语境：完整1H下降结构尚未形成时，如果反向下跌动能极强，可以把强动能作为背景，切小周期抓回调结束后的转折；但“足够强”的阈值仍未机器化。

V054还明确“交易偏向”的含义：建立做多偏向后，不是所有多信号都做；但做空信号被直接过滤。即 `BIAS_DIRECTION` 是过滤器，不是自动入场器。

## 3. 关键位置及形成

已确认位置继续包括：波段起止点、历史高低点、趋势防守/发力位、震荡边界、突破后区域、行情起始点、交易位/参考位。

V057再次把上涨发力点/防守位与上涨起始区域列为两个独立低多候选区。若没有回踩，不追价，继续等待结构演变。

V059明确补强参考位选择：在主周期寻找预期目标/参考位时，江河通常更关注前高/前低 **K线实体的开收盘区域**，而不是为了吃满行情去瞄影线极值。V057出现相同倾向。

精确区域宽度、发力点与防守位的统一选取仍是 `HUMAN_DISCRETION_REQUIRED`。

## 4. 关键位置上的价格/K线行为

持续观察：创新极值、是否有跟随、排斥、吞没、趋势K、影线、回调强弱、突破是否离开旧空间、二推/多推失败、防守位是否被破。

V061将弱回调补得更具体：两根反向K实体都很小且影线逐渐变长，被解释为反向动能减弱；之后大阳线完全吞没前方阴线构成顺向确认。

V062进一步说明排斥不是只看一根K：先出现上涨减速/回撤，而不是一鼓作气冲过关键位；随后再出现空头吞没，组合起来才形成更强的高位排斥证据。

V063下沿多单也使用两阶段确认：长下影先确认排斥，但仍不直接进，继续等大阳线吞没前方阴线。

## 5. 入场时机与触发

核心 Family 仍只有 A–D：

1. `JH-FAMILY-A` 趋势关键位回调延续；
2. `JH-FAMILY-B` 趋势衰弱反转 / 高周期回调；
3. `JH-FAMILY-C` 多周期确认突破；
4. `JH-FAMILY-D` 震荡边界反转。

V054/V059把 A/C 的组合进一步钉实：高周期强突破建立方向 → 小周期浅回调 → 防守/关键区不失守 → 二推失败、结构修复或顺向确认K → 入场。

V055展示 B 的更激进变体：高周期完整新趋势尚未形成，但单次反向推动极强 → 小周期等待回抽结束/二推失败 → 轻仓抓转折。

V058/V063继续强化 D：宽幅震荡只在边界找机会；长影/排斥只是第一层证据，最好再等吞没/明确反向K确认。

## 6. 明确不交易条件

累计 no-trade 继续扩展：

- 关键位没有确认不做；
- 震荡中间不做；
- 逆强动能不做；
- 强趋势回调过深/加速否定原推动后不做；
- 建立做多偏向后，空信号直接过滤；
- 不因快速长针直接接刀，必须等确认K；
- 距离前方关键高/低点过近、剩余空间有限时不追；
- 破位后直接追价导致止损空间过宽/RR过低时不做；
- 不标准小N只能参考，不直接触发订单；
- 回成本区本身不允许加仓；必须出现新的增强型交易理由；
- 仅有高周期位置、双底、长下影、单根大K均不能脱离背景自动触发。

## 7. 如何承认判断错误

逻辑型止损与结构另一侧止损保持核心地位。

V054：5m防守位失守则原多单候选直接放弃。

V061出现重要风险案例：第一笔半仓多单止损后，不因为“原逻辑总体没变”立即补仓，而是等价格重新回到支阻互换位置，并出现新的长下影/趋势K等条件后，才以新的0.5×风险重新建立第二单。

因此“止损后可重进”的来源边界进一步稳定为：**必须存在新的独立条件，并且总风险仍受约束。**

## 8. 盈利后的持仓管理

固定RR、固定空间、动态结构退出继续并存；江河本人总体偏好动态跟随，但会随市场质量下调利润预期。

V054：二次向上试探失败 + 大阴线 + 高周期关键高点，可主动退出。

V057/V059：弱趋势/横向背景下，可使用前高实体区域作为保守固定/参考目标，不追求影线极值。

V059：加仓会改变整体风险，来源因此把原本未预设的止盈改成两单统一前高目标，以压低新增风险暴露。

V060/V061：原本强势预期在缺乏跟随后降级成弱多，可降低盈利标准，不强行“格局”。

V062：强阴快速走出后额外等待1–2根K观察是否继续跟随；没有跟随并快速回撤时保护利润。

V063：宽幅震荡中第三次向上尝试仍缺乏强势延续，即使尚未到所有预期位也可以谨慎离场。

## 9. 仓位与风险流程

母理念仍是控制单次最大损失，止损宽则减仓、质量低则减仓，不固定手数。

V055明确：非标准/低评分、无明显加分项的订单使用 **平时0.5×仓位**。

V060明确：没有高低周期共振、只做独立5m周期时，订单质量被下调，整体仓位较轻。双周期共振因此不是绝对准入门槛，而是质量/仓位修正因子。

V061进一步出现可执行的风险拆分：有减分项时，第一单用0.5×；止损后若出现新的独立条件，第二次仍用0.5×。来源明确两次尝试合计约等于平时一笔正常订单的风险规模。

V059继续确认：加仓不是因为回到成本区，而是新增强信号出现；加仓后会重新约束两单共同止损/目标，避免总风险失控。

V030评分开仓边界 `>3` vs `>=3` 仍未解决。

## 10. 多周期协调

推荐组合 `4H+15m`、`1H+5m`、`15m+1m` 保持。

本批新增一个重要边界：**允许独立周期交易。** V058明确在1H与5m无良好共振时按5m独立做；V060进一步说明这种订单通常质量较低、仓位更轻。

所以当前来源不支持“所有订单必须双周期共振”的硬规则。更准确的是：

```text
有高低周期共振 → 质量加分
无共振但单周期条件完整 → 仍可交易，但质量/仓位下调
```

V054/V057/V059继续提供1H→5m实例；高周期负责方向/位置，低周期负责防守、二推、吞没和执行。

- V055：1H强反向动能 + 5m二推不破半仓空单；

- V059：1H强突破 + 5m二推不破多单 + 成本区新确认加仓；

- V061：强突破半仓首单止损 → 新独立条件半仓重进；
- V062：复杂内部结构重新分类后的震荡/大空重叠高位空单；
- V063：暴跌+暴涨宽幅震荡下沿，长下影后再等吞没做多。

## 12. Lookalike / Hard Negative

新增/加强：

- 打破一个发力点 ≠ 完整趋势已经形成；
- 形成偏向 ≠ 所有顺向信号都必须做；
- 回调到防守位 + 长针 ≠ 自动接刀；
- 不标准小N ≠ 可直接下单；
- 破位后马上追单 ≠ 高质量交易；
- 回成本区 ≠ 加仓理由；
- 大阳/大阴出现但没有后续跟随，质量下降；
- 双周期没有共振 ≠ 绝对禁止交易，但应降级质量/仓位；
- “裸K”标题 ≠ 来源证明永远不用任何辅助线；V061明确出现均线作为辅助证据；
- 指标/量化/跟单 ≠ 不劳而获的稳定盈利捷径，但V056并未声明所有工具永远禁止。

## 13. 明确规则 vs 主观判断

### DIRECTLY_PROGRAMMABLE / 流程级可程序化

- 标准趋势高低点延续定义；
- `BIAS=LONG` 时反向空信号过滤，但顺向信号仍需独立触发；
- 无双周期共振可进入 `SINGLE_TIMEFRAME_MODE`，来源明确质量较低/轻仓；
- 低评分案例可使用0.5×常规仓位；
- V061两次0.5×尝试合计控制在一笔常规风险语境；
- 新增信号才允许成本区加仓；
- 既有ABC数字、震荡0.5×、复盘流程等继续保留。

### MULTI_CASE_INFERABLE

- 有效突破 = 离开旧空间 + 强推进 + 跟随；
- 强推动后的浅弱回调；
- 二推失败；
- 多次创新极值失败；
- 宽幅震荡双向突破无延续；
- 市场由强到弱后降低盈利标准；
- 多分类共享许可。

### HUMAN_DISCRETION_REQUIRED

- 回调“过深/够浅”；
- 防守位/关键区精确画法；
- 前方空间是否足够；
- 排斥/吞没质量；
- 目标位是否用实体哪一侧；
- 强动能例外是否足以提前抓转折；
- 辅助均线在何种环境下参与判断。

### NOT_YET_UNDERSTOOD

- 统一强弱趋势阈值；
- 完整评分表与开仓阈值；
- 统一账户风险比例；
- 独立周期轻仓的精确倍数；
- 均线周期、参数及是否属于稳定系统模块；
- 势/位/态/动完整机器定义。

## 14. 独立策略家族

- **JH-FAMILY-A — 趋势关键位回调延续**：V054/V057/V059/V061继续强化“方向/突破背景 → 浅弱回调 → 关键/防守区域 → 顺向确认 → 结构止损 → 动态或保守目标”。
