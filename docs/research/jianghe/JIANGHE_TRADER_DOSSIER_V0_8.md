## 1. 市场分类体系

核心仍是 **趋势 / 震荡**，并区分方向、强弱、初期/末期、延续/衰弱/反转；宽幅震荡可同时容纳内部弱多/弱空偏向。

001–083 已形成“市场节奏”框架：强势/失衡市场接近直线推进、趋势K较多、回调浅；弱趋势回调更深、创新极值后拉不开距离或缺少跟随；平衡对应价值区震荡。

V084/V088/V090/V093继续反复确认宽幅震荡：强涨与强跌都能出现、双方都能触及/刺破极值，但没有一方持续延续时，应按区间/宽震荡处理。

V093新增一个重要阶段边界：**强势突破已经完成后，如果市场继续直线推进、不再给深回踩，执行逻辑可以从“等突破回踩”切换为“强趋势浅回调续势”，但这不是新Family，而是Family C进入Family A式续势阶段。**

## 2. 各行情前置条件

稳定链条：

```text
外部市场状态
→ 方向/节奏
→ 关键位置与剩余空间
→ 动能与强弱变化
→ 低周期/当下确认
→ 执行
```

V085进一步明确：技术的目的不是让交易者覆盖全部行情，而是**减少不属于自身系统的交易**。做多条件与做空条件相互独立；一个方向不成立，不自动授权相反方向。

V086/V093把强势续势补得更具体：强推进/突破后，优先接受浅、弱、缺乏跟随的逆向回调；若回调很快被顺向实体否认，可参与第二推动。

## 3. 关键位置及形成

既有位置包括波段起止、历史高低点、发力点、防守位、震荡边界、突破区域、交易位/参考位。

V084再次用最近明确下跌/上涨发力点标定宽幅震荡上下交易边界。

V088/V090继续确认：**位置首先是方向过滤器/观察区，而不是自动入场器。** 进入低多区域后，先过滤空信号，只等待新的多头许可。

V093新增来源语义：宽幅震荡关键高低位可理解为上一段行情中“亏损开始/盈利开始”发生切换的交界区域。该定义具有解释价值，但精确机器画法仍为 `HUMAN_DISCRETION_REQUIRED`。

V093还提出“真空区域”：左侧缺少明显关键位/共识位，因此新推动面临的阻力较小。其精确识别标准仍 `UNKNOWN`。

## 4. 关键位置上的价格/K线行为

持续观察创新极值、跟随、排斥、吞没、趋势K/非趋势K、影线、回调强弱、二推/多推、防守破坏。

V084重复出现：
- 空头阴线逐步减弱；
- 多头阳线重新发力；
- 由空头强转弱 + 多头弱转强形成入场证据。

V086把突破质量细分为来源术语：
- `碾压式突破`：更直接、更强势地穿越关键位置；
- `消耗式突破`：通过多次推进/回撤逐步消耗后越过。
碾压式被视为更高质量加分项，但机器阈值未知。

V090/V093继续确认：影线刺破极值、没有实体突破和后续跟随，不等于真实破位。

## 5. 入场时机与触发

核心仍只有 Family A–D。

V084：宽幅震荡下沿 → 小周期空头减弱/多头发力 → 多。

V086：原下跌不能创新低 → 最近空头发力点被强势打破并有跟随 → 强推动后弱回调立即被阳线吞没 → 强-弱-强续多。

V090：1H弱多尚未失效 + 5m震荡下沿形成重叠低多许可；错过第一点后，可等第一推动后的回调结束参与第二机会。

V093：
- 宽幅震荡上沿即使先有强阴否认，也因此前上涨强而不立即做空，等反抽结束并切1m取得更明确触发；
- 强势上涨不给深回踩时，重新分类为强市场，1m强阳收K先进入一份，5m收K再进入第二份。

## 6. 明确不交易条件

累计边界：

- 关键位无当下确认不做；
- 震荡中间不做主周期边界单；
- 弱趋势不追突破；
- 发力点、N/W、单根K、画线本身不构成交易理由；
- 对抗态未分胜负不做；
- 回成本区没有新独立信号不加仓；
- `LONG_INVALID != SHORT_VALID`；
- 趋势完整且没有转弱/失效证据时，不为抓唯一顶底机会轻易逆势；
- 系统外行情事后走远也不追；
- V093：前一方向很强时，第一根/两根反向K即使明显，也可以继续等待第二次博弈而不是立即反向入场。

## 7. 如何承认判断错误

逻辑/结构止损仍为主框架。

V084/V090继续展示上移止损后结束交易，并允许后续在出现**新独立条件**时重新建立订单。

V093提供新的主动退出样本：震荡空单虽然未硬止损，但市场迟迟无法向预期方向突破/推进，来源选择主动结束，不把“还没碰止损”理解为必须继续持有。

V079“进场K收盘价止损”文字与图示/案例冲突继续保持 review，不升级规则。

## 8. 盈利后的持仓管理

固定RR、固定目标、动态结构管理继续并存，并服从进场前定义的订单模式。

V086新增一个重要RR思路：**提高盈亏比可以通过压缩/控制进场成本，而不必只靠更长持仓。**

V088再次给出动态推止损：进入有利状态后，持续用新结构/发力点保护利润，同时保留价格直接延续的额外利润可能。

V090说明个人时间/状态可改变管理方案：晚间状态不佳时，不愿长时间持仓并可设置固定止盈。

V093强势多单因已非趋势初期而降低利润预期；若不能继续创新高则退出，达到预期后持续推进止损。

## 9. 仓位与风险流程

V079以损定仓公式仍为当前最明确机器规则：

```text
position_size = acceptable_loss / (stop_distance × value_per_point)
```

2%/1%只是教学示例，不是项目固定风险参数。

V084再次证明“分仓进入”与后续真正新增仓位需要区分；本日复盘中初始分仓后又发生了新的加仓行为，不能把两者混成同一概念。

V085/V089把风险框架进一步提高到系统层：
- 亏损是获取概率红利的正常经营成本；
- 技术分析负责提高参与大概率的质量，资金管理负责防范小概率尾部；
- 不能试图消灭全部亏损，否则可能破坏RR、频率等其他系统属性。

V089提出可直接用于复盘的分类：**模式内正常亏损 = 成本；违反模式造成的亏损 = 罚款。**

统一账户风险比例、Family之间的风险折扣仍 `UNKNOWN`。

## 10. 多周期协调

既有 `4H+15m / 1H+5m / 15m+1m` 与单周期降级模式继续成立。

本批大量 `5m→1m`：
- 5m/1H定义方向、市场状态与关键位置；
- 1m用于更精细确认/更优成本；
- 小周期不应反向改写高周期尚未失效的结构结论。

V090提供“分类重叠”的典型实例：1H弱多低多区域与5m震荡下沿同时给出低多许可，可先执行共同许可。

## 12. Lookalike / Hard Negative

新增/强化：

- 概率交易中，单笔盈利不代表行为正确，单笔亏损也不代表行为错误；
- 不能做多 ≠ 可以做空；
- 学更多技术 ≠ 应该做更多行情；
- 位置到达 ≠ 入场；
- 第一反向信号 ≠ 必须抓反转；
- 影线刺破 ≠ 真突破；
- 极短时间大R ≠ 每次短单都应期待大R；
- 无止损扛单后盈利 ≠ 正确执行；
- 别人的成功路径 ≠ 自己可直接复制的策略；
- 客观估值/“真相”正确 ≠ 交易方向一定有利润。

## 13. 明确规则 vs 主观判断

### DIRECTLY_PROGRAMMABLE
- `LONG_INVALID != SHORT_VALID`;
- 系统条件未触发 → `NO_TRADE`;
- 以损定仓公式；
- `ENTRY_SPLIT != ADDITIONAL_RISK_ADD`;
- 订单模式必须匹配退出尺度；
- 模式内亏损 vs 违反模式亏损可作为复盘分类字段；
- 单笔结果不能直接判定执行正确性。

### MULTI_CASE_INFERABLE
- 宽幅震荡；
- 强-弱-强；
- 原方向强转弱/新方向增强；
- 第二推动；
- 真/假突破；
- 弱趋势→震荡重分类；
- 分类重叠后的共同交易许可；
- 强突破后从Family C转入Family A式浅回调续势。

### HUMAN_DISCRETION_REQUIRED
- 发力点/关键区精确选择；
- 碾压式/消耗式突破质量；
- 浅/深回调；
- “真空区域”；
- 市场迟滞到什么程度应主动离场；
- 个人状态如何映射到持仓管理。

### NOT_YET_UNDERSTOOD
- V030评分阈值；
- V065完整语义；
- V069内部/外部结构术语统一；
- V078恰好50/50 K线分类边界；
- V079止损文字/画面冲突；
- 碾压式/消耗式突破机器阈值；
- 真空区域机器定义；
- 统一账户风险母规则。

V091新增市场观：价格运动被解释为参与者立场/共识的合力；“用市场反应验证共识，而不是用判断定义市场”。这是来源层市场模型，不直接变成机器指标。

## 14. 独立策略家族

核心仍只有：
- `JH-FAMILY-A` 趋势关键位回调延续；
- `JH-FAMILY-B` 趋势衰弱反转 / 高周期回调；
- `JH-FAMILY-C` 多周期确认突破；
- `JH-FAMILY-D` 震荡边界反转。

V093解决一个容易误读的边界：

```text
强势环境并非只能Family C
突破/失衡形成阶段 → C更常见
强势趋势已经形成、只给浅回调 → A的浅回调续势变体可接管
```

因此强趋势下“突破”和“浅回调续势”是不同阶段的互补执行，不创建 Family E。

`SCALPING_EXECUTION_MODE`仍为非核心模式；均线/其他指标仍为`AUXILIARY_TOOL_USAGE`。
