## 1. 市场分类系统

核心仍是 **趋势 / 震荡**，并区分方向、强弱、初期/末期、延续/衰弱/反转。

001–043 已确认：强趋势更适合突破、弱趋势更适合回调；不同周期拥有自己的结构；强趋势节奏转弱不等于高周期立即反转；弱趋势与震荡可出现重叠分类。

V045/V050进一步钉死一个重要边界：**强反向运动首先可以否定局部走势或形成“止跌/弱化”，但在新的高低点延续没有形成前，不能直接把它升级成完整趋势反转。**

V052再次出现 `弱空 / 震荡前期` 的重叠分类。来源并不要求每一刻都强行选唯一标签；如果两个合理分类都指向相同的高价值动作，可以先执行共同许可，再用后续信息重新分类。

## 2. 各行情前置条件

总体流程保持：

```text
市场环境/方向
→ 动能/节奏
→ 关键位置与剩余空间
→ 低周期确认
→ 执行
```

方向本身不够。V052明确：同样是下跌，强空与弱空的交易价值不同；回调频率、深度、是否能真正创新极值、是否有跟随都要纳入判断。

V045/V047/V052继续强化 `二推不破/二次进攻失败`，但其意义必须依赖环境和位置。

V046增加系统级前置：交易模式必须明确自己在 **胜率 / 频率 / 盈亏比** 中做什么取舍，不能在盘中来回切换目标。

V050把“应变”进一步操作化：**先在系统构建阶段准备条件与预案，盘中只等待触发，不临时发明交易理由。**

## 3. 关键位置及形成

已确认位置继续包括：波段起止、历史显著高低点、趋势防守位、震荡边界、突破后区域、行情起始点/发力点、交易位/参考位。

V052再次使用“最近空头发力位置”作为弱空/震荡前期的上方高空关键区。

V050显示高周期（日线）关键区可以来自一段强上涨与强下跌交汇形成的大分歧区域，但**高周期到位只是进入观察，不是入场许可。**

精确画区宽度、防守点/发力点选取仍为 `HUMAN_DISCRETION_REQUIRED`。

## 4. 关键位置上的价格/K线行为

持续观察：

- 是否能继续创新高/低；
- 影线刺破后是否有真实跟随；
- 排斥、吞没、强趋势K；
- 突破后的跟随与是否离开旧空间；
- 二推/多推是否失败；
- 回调实体/斜率是否逐渐减弱；
- 关键防守是否被破坏。

V045把“二推不破”补成更具体案例：低点附近空头连续两次尝试向下失败，且此前反向力量已经能走出显著空间。

V047继续证明同一震荡中可以存在内部偏向：外部仍是震荡，但内部低点抬高可提示多方略占优。

V049明确：N/W、画线等**不是市场必须遵守的图形**，只是把上述信息压缩为可识别结构。

## 5. 入场时机与触发

核心仍只有四个 Family：

1. `JH-FAMILY-A` 趋势关键位回调延续；
2. `JH-FAMILY-B` 趋势衰弱反转 / 高周期回调；
3. `JH-FAMILY-C` 多周期确认突破；
4. `JH-FAMILY-D` 震荡边界反转。

本批重要新增：

- V045：1H只先确认“止跌/弱化” → 5m低点区域二次向下失败 → 多单。
- V047：5m震荡上沿原本等1m反转空；条件没出现则不做。随后真突破有强跟随，立即取消D预案，切换到C/A的顺多回调逻辑。
- V052：1H弱空/震荡前期共享“上方关键区高空”许可 → 5m上涨动能减弱 + 二推不破 → 空单。
- V050：高周期关键位只给观察区，原强趋势未减弱时禁止直接反向接单。

## 6. 明确不交易条件

累计边界进一步加强：

- 关键位无确认不做；
- 震荡中间不做；
- 原强动能没有减弱时不逆做；
- 没有真实突破跟随时不按突破做；
- 未触发自己系统，即使行情随后飞走也不追；
- **做不了多 ≠ 自动可以做空**，两边必须分别有条件；
- 回成本区本身不能触发加仓；
- 高周期到位不能替代低周期确认；
- 向上/向下突破后如果不属于自己预案，宁可不做；
- 精神状态/环境不专注时，来源允许主动降低新增风险。

V046进一步把“放弃”提升为系统设计原则：模糊机会和不属于自身模式的利润，本来就应该被明确舍弃。

## 7. 如何承认判断错误

核心仍是逻辑止损与结构另一侧止损。

新增补强：

- V045 多单止损放下方结构极值之外；
- V052 高空案例止损放前高上方；
- V047 首单后回到成本区并不等于原判断错误，也不等于自动加仓；只有新的确认才形成第二笔独立风险；
- V049明确：**止损不是“失败”标签，而是中性的风险控制/交易成本。**

被止损后是否重进，仍必须看新证据，而不能为了补亏。

## 8. 盈利后的持仓管理

固定RR、固定空间、动态结构三类退出继续并存；江河本人仍偏好动态跟随。

V047新增完整分批管理：

```text
两笔分仓
→ 先减一笔
→ 剩余继续按结构
→ 内部N/动能明显转弱
→ 退出剩余仓位
```

V050增加一个非常重要的管理母规则：**进场时是什么交易模式，后续就按那个模式管理。** 剥头皮信号对应剥头皮利润尺度；波段信号不能因小波动临时变成超短线。

V052弱空/震荡前期案例使用两层结构目标：最近发力点 → 原趋势结构低点；只保留为该来源案例，不外推为统一双目标规则。

## 9. 仓位与风险过程

既有母理念保持：控制最大损失、止损宽则仓位更小、不同Family/质量可调整仓位。

本批新增/强化：

- V048：旅行环境导致状态不专注时，来源明确“不敢开太大仓位”；精神状态进入风险许可，但无统一量表。
- V046：不同交易模式必须接受不同的胜率/频率/RR取舍；不能既想高频、又想高胜率、又要求每单大RR。
- V049：亏损/止损被定义为概率交易中的可控成本，而不是单笔失败。
- V047：分仓进入；回成本区只有新确认才允许增加第二笔风险。

V030 `>3` vs `>=3` 的评分开仓边界仍未解决。

## 10. 多周期协调

既有推荐组合保持：`4H+15m`、`1H+5m`、`15m+1m`。

本批继续提供直接实例：

- V045：`1H → 5m`；
- V047：`5m → 1m`；
- V050：`1D → 1H → 可进一步5m`；
- V052：`1H → 5m`。

高周期负责环境/关键区/预期利润级别；低周期负责真实强弱、二推、结构确认与执行。

V050还明确：**不同级别信号对应不同订单类型和利润尺度**，不能进场后跨尺度摇摆。

## 11. 代表成功、失败与复盘案例

新增正式案例：

- V045：1H止跌候选 → 5m二推失败多单；
- V047：震荡上沿空条件未出现 → 真突破后重新分类做多 → 成本区新确认加仓 → 分批/动态退出；
- V050：日线关键区只观察、不接飞刀的条件化 `NO_TRADE` 案例；
- V052：弱空/震荡前期共享高空许可 → 1H关键区 → 5m二推失败空单。

V051新增的不是策略案例，而是完整复盘体系：战略复盘 + 战术复盘。

所有盈利、历史报告、R倍数仍只属于来源案例内容，不是策略有效性证据。

## 12. Lookalike / Hard Negative

新增重要反例：

- 强反向上涨/下跌 ≠ 已经完成高周期趋势反转；
- W底/N形/画线 ≠ 市场必须按图运行；
- 高周期关键位到达 ≠ 入场；
- 没形成做多条件 ≠ 做空条件成立；
- 原震荡上沿到了，但1m反转条件没出现 → 不做空；
- 回成本区 ≠ 自动加仓；
- 只知道方向（例如“下跌”）≠ 可以下单；
- 影线刺破前低但没有跟随 ≠ 强空延续；
- 没抓到系统外行情 ≠ 执行错误；
- 扛单/梭哈偶然盈利 ≠ 正确交易。

## 13. 明确规则 vs 主观判断

### DIRECTLY_PROGRAMMABLE / 流程级可程序化

- 已有趋势结构、ABC数字、震荡0.5×等；
- `LONG_INVALID != SHORT_VALID`；
- 未触发系统条件 → `NO_TRADE`；
- 订单记录分成“市场客观状态”和“当时主观逻辑”；
- 战术复盘动作：`CONTINUE / IMPROVE / STOP / START`；
- 战略复盘链：目标 → 结果 → 差距 → 根因 → 方案。

### MULTI_CASE_INFERABLE

- 强/弱趋势；
- 止跌/弱化 vs 完整反转；
- 二推失败质量；
- 真假突破；
- 多分类共享许可；
- 订单模式与利润尺度匹配；
- 条件→预案→执行的应变状态切换。

### HUMAN_DISCRETION_REQUIRED

- 关键位/发力点精确选择；
- 动能/排斥/二推质量；
- 精神状态；
- 个人适配性；
- 哪些技术应被融合或舍弃。

### NOT_YET_UNDERSTOOD

- 完整评分和统一账户风险；
- 胜率/频率/RR的统一统计口径与量化取舍；
- 剥头皮/波段信号的完整机器分类；
- 行动预案全集及冲突优先级；
- 势/位/态/动完整机器定义。

V049/V053进一步把其体系解释为：**技术/图形只是信息表达；最终要理解市场底层机制，在市场规律、交易规则和个人诉求的交集中形成自己的连贯系统。**

## 14. 独立策略家族

核心 Family 仍只有 A–D，没有证据创建 Family E。

### Family A — 趋势关键位回调延续
本批被 V047/V052补强：真突破或弱趋势背景下，等待回调结束/低周期确认，不能只凭方向追单。

### Family B — 趋势衰弱反转 / 高周期回调
V045和V050进一步明确“先弱化/止跌，再等低周期证据”；V045提供低点二次失败多单案例，V050提供日线关键区不接飞刀的观察案例。

### Family C — 多周期确认突破
V047给出非常清楚的 `D未触发 → 真突破强跟随 → 切C → 回调结束做多` 的实时切换；突破后仍依赖低周期确认。

### Family D — 震荡边界反转
V047继续确认只做边界且到位后等低周期失败结构；V052表明弱趋势/震荡前期可能共享同一个边界高空许可。

### NON-FAMILY：SCALPING_EXECUTION_MODE
仍保持非核心。V050进一步说明剥头皮订单必须按剥头皮信号/成本/利润尺度管理，不能进场后临时当成波段。

本版本未访问 outcome/validation/final；`SOURCE_ONLY_VERIFIED=NO`，仍不是 PRIMARY-ready。
