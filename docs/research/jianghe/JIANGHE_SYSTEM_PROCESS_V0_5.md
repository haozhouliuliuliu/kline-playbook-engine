# 江河交易系统设计/执行/复盘过程 V0.5（001–063）

本文件只整理来源中已经明确出现的“系统如何被构建、执行和复盘”。它不是机器策略，也不补任何来源没有给出的参数。

## 1. 市场信息不是图形因果

- N/W、画线、关键区只是对市场信息的压缩表达；图形本身不是原因。
- 需要还原成：哪一方能否创新极值、是否跟随、动能强弱、空间、结构成本、位置。
- `PATTERN_NAME != TRADE_PERMISSION`。

## 2. 系统先设计，盘中识别条件并调用预案

来源累计形成：

```text
构建阶段：定义市场分类、条件和行动预案
盘中阶段：识别当下触发了哪些条件
执行阶段：调用对应预案
未触发：NO_TRADE
```

“应变”不是即兴预测，而是在已有方案之间根据新信息切换。

## 3. 交易偏向是过滤器，不是触发器

V054明确补充：

```text
BIAS=LONG
→ 多信号：仍需判断是否满足完整交易条件
→ 空信号：直接过滤
```

所以 `BIAS_DIRECTION != ENTRY_TRIGGER`。

## 4. 多周期共振是质量修正，不是普遍硬门槛

既有推荐组合仍为：`4H+15m`、`1H+5m`、`15m+1m`。

V058/V060新增明确边界：

```text
如果高低周期形成共振
→ 质量加分

如果没有共振，但单周期自身条件完整
→ 可以进入 SINGLE_TIMEFRAME_MODE
→ 订单质量下调
→ 来源倾向轻仓
```

因此项目后续不得错误冻结成“没有双周期共振一律不交易”。精确质量折扣和仓位倍率仍UNKNOWN。

## 5. 质量评分可以通过仓位表达，而不只有做/不做二元结果

来源已反复出现：

- 震荡相对常规仓位0.5×；
- ABC总风险分份；
- V030评分影响仓位；
- 左侧/剥头皮缩仓；
- 精神状态不佳减少新增风险；
- V055非标准、低评分、无加分项订单直接0.5×；
- V061有减分项的第一笔0.5×，止损后新条件第二笔仍0.5×。

这支持一个来源层母概念：`TRADE_QUALITY` 不一定只输出 `TRADE/NO_TRADE`，还可以影响仓位和利润预期。但统一评分公式仍UNKNOWN。

## 6. 多次尝试仍受总风险预算约束

V061是目前最清楚的实例：

```text
第一次机会：0.5×常规仓位 → 止损
出现新的独立条件
第二次机会：0.5×常规仓位
两次合计风险规模 ≈ 平时一笔常规订单
```

这不是摊平旧亏损，而是两个独立条件下的分拆尝试。是否存在跨Family通用的“尝试预算”规则仍UNKNOWN。

## 7. 回到成本区不是加仓理由

V059进一步确认：

```text
回成本区
≠ ADD

回成本区 + 新的增强型独立进场证据
→ 可以考虑新增一笔风险
```

加仓后必须重新考虑总风险、止损和盈利目标；本例因此把两笔订单统一到同一结构止损和前高参考目标。

## 8. 参考目标不等于固定止盈

V057/V059重复出现：江河在主周期前高/前低位置进行参考时，常偏向使用K线实体的开/收盘区域，而不是为了“吃满”行情去瞄影线极值。

同时来源多次明确“不预设止盈”，因此：

```text
REFERENCE_TARGET != HARD_TAKE_PROFIT
```

它可以是动态管理中的观察点，也可以在弱趋势/横向背景下被转换成预设目标。具体适用范围仍UNKNOWN。

## 9. 市场质量变化会改变盈利期待

V060/V061进一步强化：

- 原本强动能没有跟随、转为弱趋势后，可降低盈利标准；
- 低质量/无大周期共振订单，不需要强行追求大目标；
- 二推失败、反向大K、关键区压制等可触发主动保护利润。

这和既有“进场模式决定管理尺度”并不冲突：仍然要在原模式框架内根据市场状态动态调整，而不是把日内单任意改成波段单。

## 10. 宽幅震荡是“双向突破无延续”的状态，而不是单纯横线框

V058/V063提供稳定来源例：

- 能创新高；
- 也能创新低；
- 但两边突破后都无法持续跟随/快速收回；
- 甚至暴涨、暴跌同时出现。

此时高空低多仍需边界确认，不能仅因为价格来到边界就入场。

## 11. 辅助工具不自动等于核心策略

V056反对的是把指标、量化、跟单当作不劳而获的稳定盈利捷径。

V061原视频又明确使用一根均线作为重进场的辅助证据之一。因此当前最保守来源化结论是：

```text
核心逻辑：结构 / 动能 / 位置 / 多周期 / 风险
辅助工具：可以存在
辅助工具是否必需：UNKNOWN
```

不得把“裸K”标题机械解释成“任何辅助线永远禁止”，也不得因为一次均线使用就创建指标策略Family。

## 12. 系统设计取舍与复盘闭环保持不变

- 胜率 / 频率 / 盈亏比不能同时追求极致；
- 进场前确定订单类型与利润尺度；
- 止损/亏损是概率成本，不自动等于失败；
- 复盘分战略与战术：目标→结果→差距→根因→方案，以及 `CONTINUE / IMPROVE / STOP / START`；
- 技术最终必须适配个人并形成连贯体系。

## 13. 当前仍未解决

- 统一交易质量评分及开仓阈值；
- 无多周期共振时的固定质量折扣/仓位倍率；
- 低评分多次尝试的统一总风险上限；
- 主周期实体参考位的跨Family适用范围；
- 均线的参数、使用条件与稳定系统地位；
- 强弱趋势、回调深浅、有效跟随等机器阈值；
- 完整账户风险母规则。
