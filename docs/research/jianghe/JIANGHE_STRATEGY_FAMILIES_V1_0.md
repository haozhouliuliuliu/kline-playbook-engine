# 江河交易员策略家族规格 V1.0（001–099 Final）

本文件是来源化研究规格，不是机器策略或交易授权。核心 Family 仍只有 A–D；风险/行为治理不创建新Family。

## JH-FAMILY-A：趋势关键位回调延续

| 字段 | V1.0来源化规格 |
|---|---|
| applicable_market | 已确认趋势、或突破完成后形成的延续环境 |
| preconditions | 势/方向优先；位置有价值；前一推动有质量；反向回调相对弱且未快速否定原推动 |
| location | 趋势防守/发力位、突破后回踩区、浅回调/第二推动前区域 |
| trigger | 顺向确认K、吞没、二推失败后恢复、新方向重新发力；形态必须置于势与位之后 |
| no_trade | 位置差、空间不足、回调过深/反向加速、对抗未分胜负、只有形态无背景 |
| stop_or_invalidation | 回调/入场结构极值外、最后防守位失守、原趋势无法延续并被反向持续否认 |
| management | 动态结构、关键空间或固定RR均可；趋势初期可更右侧，非初期可更早保护 |
| position_risk | 以损定仓；质量/评分/共振/状态可修正风险预算；统一账户百分比UNKNOWN |
| timeframes | 高周期定势与位，真实低周期读触发 |
| human_discretion_fields | 回调深浅、推动质量、关键区、趋势阶段、剩余空间 |
| unknown_fields | 强弱阈值、趋势阶段统一机器算法、统一风险母规则 |

## JH-FAMILY-B：趋势衰弱反转 / 高周期回调

| 字段 | V1.0来源化规格 |
|---|---|
| applicable_market | 原趋势末期/衰弱，或高周期关键区域中的低周期反向机会 |
| preconditions | 原方向先失去延续/创新能力；仅减弱不够，新方向还需真实跟随/接管 |
| location | 高周期关键/参考位、原趋势防守区、震荡外部边界附近 |
| trigger | 无法创新极值、防守破坏、反抽失败、强反向行为后出现接管证据 |
| no_trade | 完整趋势中盲目抄顶底；只见第一反向K；新方向没有跟随；同周期内部结构直接当入口 |
| stop_or_invalidation | 新方向无法延续、原方向恢复、结构另一侧 |
| management | 按订单模式与趋势阶段选择固定/空间/动态退出 |
| position_risk | 左侧、低质量、状态差可缩仓；统一比例UNKNOWN |
| timeframes | 高周期给环境/位置，低周期给真实反向行为 |
| human_discretion_fields | 转弱质量、接管质量、第二次博弈、阶段 |
| unknown_fields | 反转机器阈值、爆发阈值、统一仓位规则 |

## JH-FAMILY-C：多周期确认突破

| 字段 | V1.0来源化规格 |
|---|---|
| applicable_market | 强势/失衡启动，或结构/区间真实突破 |
| preconditions | 价格真正离开旧空间；实体破位与同向跟随；不能快速回收 |
| location | 外部边界、发力/防守点、突破后回踩区 |
| trigger | 决定性突破+收K/跟随+需要时的真实低周期确认 |
| no_trade | 影线刺破、无跟随、快速收回、旧空间内重叠对抗、消耗过大质量不足 |
| stop_or_invalidation | 重回旧空间并被持续否认、突破结构失效、结构另一侧 |
| management | 突破形成稳定趋势后可切Family A浅回调延续 |
| position_risk | 以损定仓；质量影响风险预算；统一质量折扣UNKNOWN |
| timeframes | 外部周期定边界；低周期确认必须在真实低周期识别 |
| human_discretion_fields | 碾压式/消耗式、跟随质量、突破距离、回调强弱 |
| unknown_fields | 距离/速度/跟随量化阈值 |

## JH-FAMILY-D：震荡边界反转

| 字段 | V1.0来源化规格 |
|---|---|
| applicable_market | 已确认震荡/宽幅震荡，两边推动都缺持续延续 |
| preconditions | 只在外部上下高价值边界；允许高周期弱趋势与低周期震荡共享同向许可 |
| location | 外部最高/最低区、最近发力/防守边界 |
| trigger | 边界假突破、二推/多推失败、强弱转换、吞没、新方向发力 |
| no_trade | 主周期中间、只到边界无确认、第一反向K不足、真突破后仍坚持反转 |
| stop_or_invalidation | 外部边界真实突破并持续跟随、结构另一侧 |
| management | 相对主动；动态结构/关键空间/固定RR按模式使用 |
| position_risk | 既有震荡0.5×只保留对应来源语境；以损定仓约束总风险 |
| timeframes | 主周期定外部边界；小周期只负责细化触发 |
| human_discretion_fields | 边界画法、二推质量、主动退出时点 |
| unknown_fields | 宽幅边界算法、统一风险比例、退出统一公式 |

## Family间切换

- D真突破并形成跟随 → 可切C。
- C突破后进入稳定趋势 → 可切A的浅回调/小转折续势。
- B只有在原趋势衰弱/否认且新方向接管时成立，不等于完整趋势中盲目逆势。
- 分类重叠可以共享同方向许可；不必为了标签唯一而扭曲来源。

## Cross-family rules

- V007：优先级稳定为 **势/趋势 > 位/位置 > 态/形态**；形态不独立交易。
- V018/V069：同周期内部结构只作确认/重分类/管理参考，不独立提供入场逻辑。
- V017：退出方式与订单模式、趋势阶段一致；固定RR/关键空间/动态结构均是来源允许的不同方法。
- V099：质量影响风险预算；账户资金上限/物理隔离属于跨Family风控，不是新Family。
