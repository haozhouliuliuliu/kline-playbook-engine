# 江河交易系统设计/执行/复盘过程 V0.7（001–083）

本文件只整理来源已经明确出现的系统构建、盘中执行、风险和复盘过程，不补来源没有给出的参数。

## 1. 构建、盘中执行、复盘三阶段

累计来源继续支持：

```text
系统构建/盘前：设计条件、预案、风险、订单模式
盘中：客观识别是否触发既有条件，并执行
盘后：用记录/样本检查执行和系统缺口
```

“应变”不是盘中即兴找理由，而是在预设方案之间根据当下条件切换。

## 2. 市场节奏决定交易手法

V075把适配关系进一步明确：

```text
强势/失衡/低回调节奏 → 更适合突破
弱趋势/深回调/缺少跟随 → 更适合回调交易
平衡/震荡 → 边界交易，不追随
```

并给出交易者可能经历的三个阶段：所有节奏只用一种方案；只做自己熟悉节奏、其他等待；为不同节奏准备不同方案。第二与第三阶段不分高下，更多机会也意味着更多风险，最终可以主动做减法。

## 3. 形态只是信息压缩，不是因果

V076/V078再次正式化：

```text
先有市场资金/行为变化
→ 后有K线/结构/形态
→ 图形只是压缩信息
→ 读取强弱/方向/动能/位置
→ 再匹配交易方案
```

`PATTERN_NAME != TRADE_PERMISSION`。

## 4. K线强弱是动态比较

V078把K线理解拆成：

- 趋势型K：实体占整根K约50%以上；
- 非趋势型K：影线占整根K约50%以上；
- 整根大小、实体大小、影线大小要与左侧K比较；
- 单根K本身不能作为交易理由；
- 重点是连续K线的强弱变化过程。

V078还形成信号语法：

```text
同向弱→强
同向强→弱
旧方向强→弱 + 新方向弱→强
旧方向强→弱 + 新方向直接强
趋势中原方向强 → 弱回调 → 原方向再强
```

如果中间回调本身仍强，则不属于“强-弱-强”。

## 5. 对抗态是等待状态

V078正式定义：旧方向没有减弱，同时新方向也很强，可能伴随吞没，属于双方激烈对抗。此时没有一方明显碾压另一方：

```text
CONFLICT_STATE=true
→ NO_TRADE
→ 等第二次博弈/连续跟随
→ 胜负更清楚后再跟随
```

## 6. 发力点是攻防/节奏信息，不是开仓按钮

V078/V079统一：发力点是强弱转换后引起推动的博弈转换位置。

- 发力点顺同方向移动 → 可辅助识别趋势/失衡；
- 发力点高低混乱 → 可辅助识别震荡/平衡；
- 发力点少、间隔远 → 来源解释为掌控更稳定、分歧更少；
- 发力点密集 → 分歧更多、行情更不稳定；
- 最近发力点被对方打破 → 可作为控制权变化的重要证据；
- 发力点可起潜在支撑阻力作用，但**不能单独成为开单理由**。

数量/间距的机器阈值仍UNKNOWN。

## 7. 时间周期是价格呈现工具

V078/V072共同支持：不同周期描述的是同一价格过程，但聚合尺度不同。

```text
大周期一根K
≈ 小周期内部的一段趋势/震荡过程
```

这不等于可以把同周期内部结构直接冒充下一小周期外部结构。若需要交易更小周期，仍必须真正切到该周期重新识别其结构。

## 8. 历史提供参考，当下负责触发

V078把这一点写成明确原则：历史平衡/失衡、发力点和边界可以给交易背景，但不能只因历史位置到达就下单。必须看当下K线/强弱反应。

因此：

```text
HISTORICAL_CONTEXT != ENTRY
HISTORICAL_CONTEXT + CURRENT_BEHAVIOR → POSSIBLE_TRIGGER
```

## 9. 风险是先定义可承受亏损，再反推仓位

V079给出来源化公式：

```text
仓位 = 可承受亏损 / (止损点数 × 每点价值)
```

流程：

1. 先定账户/订单可承受最大亏损；
2. 根据入场与止损之间距离计算止损点数；
3. 根据标的每点价值反推仓位；
4. 止损更宽则降低仓位/杠杆，止损更窄则可提高。

V079中的2%与1%都是教学例子，不是项目可以锁定的账户风险参数。

## 10. 分仓进入与风险加仓必须区分

V081明确：原本计划10手，可拆成5手+5手在不同价位执行。这属于同一预设风险的 `ENTRY_SPLIT`，而不是第一笔后临时增加风险的加仓。

```text
ENTRY_SPLIT != ADDITIONAL_RISK_ADD
```

真正加仓仍要求新的独立/增强型进场条件并受总风险约束。

## 11. 订单类型在进场前定义，退出按原模式评价

V050/V073/V074/V080共同支持：

```text
进场前定义：剥头皮 / 微波段 / 波段等
→ 决定预期空间、容忍波动、退出速度
→ 持仓中保持模式一致
```

是否“卖飞”不能事后看行情走多远。剥头皮按短线逻辑退出，即使后来走出大趋势也不等于错误；趋势单因为微小波动提前退出才可能属于执行偏离。

V074再次明确：江河本人核心日常交易仍以日内波段/微波段为主；剥头皮大量出现在内容中，不代表核心风格转型。

## 12. 系统信心与来源中的回测观点

V080主张：有系统但拿不住单，可能因为对系统缺乏信心；来源建议通过大量历史回测/重复练习形成信心与执行习惯。如果大量样本仍稳定亏损，应修改系统而不是强迫执行。

这只是 `TRADER_SOURCE_PROCESS`。本项目当前 `SOURCE_ONLY_VERIFIED=NO`，该来源观点**不构成项目进行 outcome backtest 的授权**。

## 13. 学习流程必须从记忆走向可复用体系

V082给出：

```text
浏览
→ 记忆
→ 理解
→ 应用
→ 分析
→ 独立判断
→ 创造
→ 高频重复/反思/迁移内化
```

其中“分析”层要求把知识串成完整执行链：

```text
趋势
→ 关键位
→ 入场信号
→ 结构失效止损
→ 由止损空间计算仓位
→ 趋势/空间目标
→ 盈亏比预期
```

## 14. 过程正确与单笔结果必须分开

V083继续强化 hard negative：无止损、重仓梭哈、偶然抓到大行情，即使一次利润巨大，也不代表行为可复制或过程正确。

V083把“技术约70%、认知/思维/性格约30%”作为说明技术不是全部的修辞框架。该比例不是统计模型权重；可保留的来源语义是：技术提供材料，逻辑/认知负责把材料组织成系统并影响执行行为。
